> ⚠️ **占位文章** —— 请替换为你自己的内容。

欢迎！这是我新网站的第一篇文章。本站基于 [Hugo](https://gohugo.io/) 与
[Blowfish](https://blowfish.page/) 主题构建，托管在 GitHub Pages 上，
由 GitHub Actions 自动构建部署。

## 你可以期待什么

- 研究与工程笔记
- 项目日志
- 不定期教程

## Markdown 功能展示

支持**加粗**、*斜体*、`行内代码`。列表：

1. 有序列表可用
2. 无序列表同样可用

引用块：

> 简单是一种美德，但达成它需要艰苦的工作。—— Edsger W. Dijkstra

表格：

| 功能     | 支持 |
| -------- | ---- |
| KaTeX    | ✅   |
| 目录     | ✅   |
| RSS      | ✅   |

代码块自带语法高亮和复制按钮：

```python
def greet(name: str) -> str:
    """一个极小的占位函数。"""
    return f"Hello, {name}!"


if __name__ == "__main__":
    print(greet("world"))
```
